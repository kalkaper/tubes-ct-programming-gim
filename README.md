# Tugas Besar Clan Programming Grup 15
Selamat datang di game kami. Sebelum bermain, ada beberapa hal yang perlu dibaca untuk lebih memahami cara kerja game ini
1. Setelah menjalankan gamenya, terdapat 2 tombol, yaitu tombol segitiga dan tombol dadu.
2. Tombol segitiga memulai level yang sudah dibuat secara manual.
3. Tombol dadu membawa pemain ke menu baru.
- Pemain dapat memasukkan seed di kotak yang disediakan lalu menekan enter
- Jika ingin menggunakan seed random, kosongkan saja, tetapi **klik kotak terlebih dahulu** sebelum menekan enter.
4. Gunakan WASD atau arrow key untuk bergerak.
5. Saat bermain sebuah level, pemain dapat menekan tombol Q untuk menyimpan permainan saat ini dan tombol E untuk memuat permainan yang sudah disimpan.
- Fitur ini dapat digunakan seandainya pemain merasa salah gerak dan ingin kembali ke gerakan-gerakan sebelumnya.
